FEATURED PROJECT / 01

Estación Meteorológica IoT

Telemetría y predicción microclimática mediante IA

Sistema IoT diseñado para adquirir variables meteorológicas mediante sensores conectados a un ESP32, transmitir los datos, almacenarlos y visualizarlos mediante un dashboard web.

El sistema incorpora procesamiento de datos y modelos de machine learning para explorar la posibilidad de realizar predicciones microclimáticas.
